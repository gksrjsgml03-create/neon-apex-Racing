# NEON APEX Racing

**드리프트로 충전하고, 차원을 전환하며, 친구와 함께 달리는 3D 카트 레이싱 게임**

Windows 데스크톱에서 실행하는 카트 레이싱 개발 프로젝트입니다. 5개 테마 코스에서 AI와 기록에 도전하거나, 초대로 모인 2~8명의 플레이어가 같은 방에서 실시간으로 경주합니다.

> 현재 게임 버전: **V1.6.0 · Online Edition**
>
> 상태: **개발 중인 프로토타입** · Windows x64 · 실제 3D 렌더링 · 싱글플레이 / 멀티플레이

## 프로젝트 소개

아케이드 카트 레이싱의 드리프트와 속도감을 바탕으로, **페이즈 전환을 언제 사용할지 선택하는 주행**을 더했습니다. 부스터를 모아 직선에서 사용하거나, 에너지를 소모하는 다른 주행 모드로 전환하는 전략을 실험합니다.

카트라이더에서 영감을 받은 독립 개발 프로젝트이며, 넥슨의 공식 게임이나 관련 서비스가 아닙니다. 원작 로고·캐릭터·음원을 배포하지 않습니다. 캐릭터와 카트는 코드로 제작한 스타일화된 모델이고 음악·효과음은 Web Audio로 합성합니다.

기획 소개 예시:

> “드리프트를 끊어도 충전량이 남는 부스터와 에너지를 소모하는 페이즈 전환을 조합하고, 서로 다른 노면의 코스를 친구들과 달릴 수 있는 카트 레이싱을 만들었습니다.”

이 설명은 프로젝트의 구현 특징입니다. 기존 상용 게임의 모든 버전에 해당 기능이 없다는 비교 주장을 뜻하지 않습니다.

## 구현된 기능

| 구분 | 내용 |
| --- | --- |
| 실제 3D 화면 | Three.js / WebGL 기반 트랙·차량·캐릭터·조명·그림자 |
| 카메라 | 차량 뒤를 따라가는 기본 시점 / 넓은 시점 |
| 싱글플레이 | 플레이어 1명 + AI 5대, 3랩 경주, 맵별 최고 기록 |
| 멀티플레이 | 2~8명, 초대 기반 방, 방장 맵 선택, 준비 및 동시 출발 |
| 부스터 | 드리프트 충전 유지, 100%마다 부스터 1개 지급, 아이콘과 보유 수 표시 |
| 충돌·복귀 | 속도에 따른 튕김, 강한 충돌 시 전복, R 복귀와 1초 보호 |
| 노면 | 아스팔트·모래·흙·자갈·목재·얕은 물·눈·빙판 |
| 외형 | 캐릭터 6종 / 카트 5종, 선택 내용 로컬 저장 |
| 사운드 | 메뉴부터 이어지는 배경음악, 엔진·주행·드리프트·부스터·충돌 효과음 |
| 배포 형태 | 브라우저나 웹 서버 없이 실행하는 Windows 데스크톱 앱 |

### 페이즈 전환

- **E**를 눌러 STREET / FLUX 주행 모드를 전환합니다.
- FLUX 진입에는 페이즈 에너지 **25% 이상**이 필요합니다.
- FLUX에서는 주행 성능과 접촉 규칙이 달라지고 중앙 가속 구간을 이용할 수 있습니다.
- 사용 중 에너지가 줄어들며 소진되면 STREET으로 돌아갑니다.
- 페이즈 에너지와 부스터 충전 게이지는 서로 다른 자원입니다.

### 드리프트와 부스터

1. 전진하면서 **Shift + 방향키**로 드리프트합니다.
2. 드리프트를 끝내도 쌓인 충전량은 유지됩니다.
3. **100%에 도달하면 게이지를 0%로 비우고 부스터 1개를 저장**합니다.
4. 전진 중 **Ctrl**로 사용합니다. 사용 중에는 중복 사용하지 않습니다.
5. 보유 수가 0이면 아이콘을 숨기고, 1개 이상이면 왼쪽 충전 바 위에 아이콘과 개수를 표시합니다.

## 실행 방법

### 실행 파일을 전달받은 경우

1. 압축 파일을 받았다면 먼저 전체 압축을 풉니다.
2. `Neon Apex-win32-x64` 폴더 안의 **`NeonApex.exe`**를 실행합니다.
3. 메인 화면에서 **싱글플레이** 또는 **멀티플레이**를 선택합니다.

**exe 파일만 따로 옮기지 마세요.** `resources`를 포함한 실행 폴더 전체가 필요합니다. 실행용 폴더에는 엔진이 포함되어 있어 Node.js를 별도로 설치하지 않아도 됩니다.

현재는 서명되지 않은 휴대용 개발 빌드이며, 설치 프로그램·스토어 패키지·자동 업데이트 기능은 제공하지 않습니다.

### GitHub 소스로 실행하는 경우

이 저장소에는 소스와 버전 이력을 올립니다. `dist/`와 `node_modules/`는 포함하지 않으므로 GitHub의 **Download ZIP은 완성된 실행 파일이 아닙니다.**

필요한 환경:

- Windows x64: 현재 데스크톱 패키징 대상
- **Node.js 24 LTS**와 npm: 프로젝트 개발·빌드 기준
- Git: 저장소를 복제할 때 사용
- WebGL 2를 지원하는 그래픽 환경
- 최초 의존성 설치 시 인터넷 연결

```powershell
 git clone https://github.com/gksrjsgml03-create/neon-apex-Racing.git
 cd neon-apex-Racing
 npm ci
 npm start
```

Electron 설치 스크립트가 차단되어 실행 엔진이 없을 때만 다음을 실행합니다.

```powershell
 node node_modules/electron/install.js
 npm start
```

프로젝트 루트의 `start-game.cmd`도 사용할 수 있습니다. 빌드된 게임이 있으면 실행하고, 없으면 설치된 개발 환경으로 시작합니다.

### Windows 실행 폴더 만들기

```powershell
 npm run build:win
```

출력 위치:

```text
 dist/
 └─ Neon Apex-win32-x64/
    ├─ NeonApex.exe
    ├─ resources/
    └─ 실행 엔진 및 라이선스 파일
```

빌드 결과는 Git에 커밋하지 않습니다. 배포할 때는 실행 폴더 전체를 압축하여 전달합니다.

## 조작법

| 키 | 동작 |
| --- | --- |
| ↑ / W | 가속. 후진 중에는 먼저 제동한 뒤 전진 |
| ↓ / S | 브레이크. 계속 누르면 정지 후 후진 |
| ← → / A D | 좌우 조향. 후진에서도 누른 방향으로 이동 |
| Shift + 조향 | 드리프트 |
| Ctrl | 저장한 부스터 사용 |
| E | 페이즈 전환 |
| R | 약간 뒤쪽의 지점에서 복귀, 1초 충돌 무적 |
| C | 기본 추적 / 넓은 카메라 시점 |
| Esc | 싱글 일시 정지 / 온라인 조작 메뉴 |
| F11 | 전체 화면 / 창 모드 |

좌우 Shift와 Ctrl을 모두 지원합니다. 속도계의 `R · REVERSE`는 후진 상태 표시입니다. 무적 중에는 R을 연속으로 사용할 수 없습니다.

**온라인에서 Esc를 눌러도 전체 경기는 멈추지 않습니다.** 자신의 입력만 해제됩니다. 창을 벗어나면 싱글은 정지하고 온라인은 조작 메뉴를 표시합니다.

## 다섯 개의 코스

| 단계 | 이름 | 주요 노면·특징 |
| --- | --- | --- |
| 1 · 입문 | 코랄 코스트 | 넓은 해안 대로, 모래사장, 얕은 물 |
| 2 · 초급 | 포레스트 리본 | 숲속 흙길, 나무 다리, S커브와 고저차 |
| 3 · 중급 | 레드록 헤어핀 | 사막 모래, 자갈길, 협곡 헤어핀 |
| 4 · 고급 | 알파인 스위치백 | 설산 눈길, 빙판, 연속 급커브 |
| 5 · 마스터 | 네온 오버패스 | 4차로 도심 고가도로, 시케인과 급커브 |

모든 코스는 처음부터 선택할 수 있습니다. 노면에 따라 속도와 조향 접지력이 다릅니다. 미니맵과 실제 주행 경로는 같은 코스 데이터를 사용합니다.

## 캐릭터와 카트

- 캐릭터: **에이스 / 로지 / 쉐도우 / 루키 / 바오 / 비트**
- 카트: **블루 볼트 / 핑크 팝 / 블랙 엠버 / 썬샤인 / 그린 레인저**

싱글플레이 선택 화면에서 외형을 고를 수 있습니다. 선택한 외형은 로컬에 저장되며 멀티플레이 참가 시에도 사용합니다. 현재 외형에 따른 성능 차이는 없습니다.

## 멀티플레이

### 같은 공유기에서 함께 플레이

1. 방장이 **멀티플레이 → 닉네임 → 내 PC에서 방 열기**를 선택합니다.
2. 대기실에서 맵을 고르고 **초대 복사**로 초대 정보를 친구에게 전달합니다.
3. 친구는 **멀티플레이 → 초대 정보 붙여넣기 → 참가하기**를 선택합니다.
4. 참가자가 **준비 완료**를 누르면 방장이 **레이스 시작**을 누릅니다.
5. 경기 결과를 확인하고 방장이 대기실로 돌아가면 다음 맵을 준비할 수 있습니다.

**최소 2명, 최대 8명**이며 멀티에는 AI가 들어오지 않습니다. 같은 버전의 게임을 사용하세요. 방화벽과 Wi-Fi의 기기 간 통신 설정에 따라 연결 허용이 필요할 수 있습니다.

초대 정보에는 서버 주소와 6자리 방 코드가 함께 들어갑니다. 게임이 메시지를 대신 보내지는 않으며, 사용자가 원하는 메신저로 전달합니다.

### 서로 다른 인터넷에서 플레이

**공개 게임 서버는 아직 운영하지 않습니다.** 저장소 공개만으로 인터넷 게임 서버가 생기는 것은 아닙니다.

**멀티플레이 → 인터넷 친구와 방 만들기 → 초대 복사**로 친구를 초대하세요. 무료 임시 서버는 운영자 PC가 켜져 있어야 합니다. [무료 체험 및 호스팅 안내](PUBLIC_SERVER.md)

자세한 방법: **[ONLINE.md — 접속·방화벽·서버 배포·경기 규칙](ONLINE.md)**

### 온라인 경기 규칙

- 방장만 맵을 선택하고 출발시킬 수 있습니다. 맵 변경 시 다른 참가자는 다시 준비해야 합니다.
- 서버가 주행·충돌·부스터·랩·순위를 계산합니다. 클라이언트는 조작 입력을 전송합니다.
- 첫 완주 후 나머지 참가자에게 **45초**를 주며 전체 경기는 최대 **10분**입니다.
- 결과는 완주 여부, 완주 시간, 진행 거리 순으로 정합니다.
- 연결 종료자는 경기에서 빠지고, 방장이 나가면 다른 참가자가 방장 권한을 이어받습니다.
- 내 PC 서버를 연 경우 해당 PC의 앱을 종료하면 서버도 종료됩니다. 방장 권한 승계가 서버 이전을 뜻하지는 않습니다.

## 사운드와 저장 데이터

앱을 시작하면 메뉴·대기실·경기·결과 화면에서 배경음악이 이어집니다. 음악과 효과음 볼륨을 따로 조절하거나 **SOUND** 버튼으로 음소거할 수 있습니다. 일시 정지 중에도 배경음악은 유지합니다.

개인 최고 기록, 외형, 선택 맵, 볼륨, 최근 서버 주소와 닉네임은 해당 PC의 앱 저장소에 보관합니다. 계정 기반 클라우드 저장은 제공하지 않습니다. 온라인 방과 경기 상태는 서버 메모리에 있으므로 서버를 재시작하면 사라집니다.

최초 폰트 로드에는 Google Fonts 연결이 사용될 수 있으며, 연결되지 않으면 시스템 폰트로 표시합니다. 게임 음악은 외부 음원 다운로드 없이 합성합니다.

`src/render.js`와 일부 배경 코드는 이전 2.5D 구현의 흔적 또는 메뉴 썸네일 용도로 남아 있습니다. 현재 주행 화면은 `src/three/renderer.js`를 사용합니다.

### 자주 사용하는 명령

| 명령 | 용도 |
| --- | --- |
| `npm start` | 데스크톱 개발 실행 |
| `npm run build:win` | Windows 배포 폴더 생성 |
| `npm run start:server` | 게임 전용 온라인 서버 실행 |
| `npm run start:web` | 개발용 로컬 웹 미리보기 |
| `npm run test:online` | 방 규칙·실제 로컬 WebSocket 연결 검사 |
| `npm run test:update` | 부스터·충돌·복귀·노면 검사 |
| `npm run test:3d` | 3D 좌표·코스 폭·가드레일 검사 |
| `npm run test:controls` | 키 매핑·후진 검사 |
| `npm run test:content` | 5개 코스·랩 검사 |
| `npm test` | 기본 경주 규칙 검사 |
| `npm run check` | 주요 파일의 구문 검사 |

변경한 기능과 연관된 검사만 선택해서 실행합니다. 문서나 간단한 외형 수정 때문에 게임 전체 검사를 반복할 필요는 없습니다. 웹 미리보기는 개발 보조 수단이며 내장 서버 시작 등 데스크톱 전용 기능은 앱에서 확인합니다.

## 현재 한계와 향후 개발

**구현 완료:** Windows 앱, 3D 추적 시점, 싱글 경주, 5개 코스, 드리프트·부스터·복귀, 초대 기반 2~8명 온라인 방.

**아직 제공하지 않음:**

- 상시 운영되는 공개 서버, 계정·친구 목록·공개 매칭
- 경기 중 재접속, 관전 참가, 영구 온라인 기록
- 모바일 앱, 스토어 배포, 자동 업데이트, 결제
- 상용 수준의 지연 보정·운영 보안·대규모 부하 검증
- 자유 주행 강체 차량 시뮬레이션

현재 주행과 전복은 트랙 진행 거리와 횡방향 위치를 사용하는 아케이드 방식입니다. 상용 게임 수준의 정교한 차량 물리나 아트 품질을 구현한 상태는 아닙니다.

공개 서버에 배포하기 전에는 실제 다른 네트워크에서의 접속, 지연, 동시 접속 부하와 운영 환경을 추가 확인해야 합니다. 로컬에서 확인한 동작이 모든 인터넷 환경의 안정성을 보장하지는 않습니다.

## 문제 해결

| 증상 | 확인할 내용 |
| --- | --- |
| 실행 파일이 없음 | GitHub에는 소스가 올라갑니다. 의존성 설치 후 빌드하거나 전체 실행 폴더를 전달받으세요. |
| Electron을 찾지 못함 | `npm ci`와 Electron 설치 스크립트 허용 여부를 확인하세요. |
| 3D 화면을 시작하지 못함 | 그래픽 드라이버, WebGL 2 지원 환경을 확인하세요. |
| 소리가 들리지 않음 | 게임 SOUND 상태, 음악·효과음 볼륨, Windows 볼륨 믹서를 확인하세요. |
| 친구가 방에 접속하지 못함 | 서버가 실행 중인지, 초대 주소가 친구에게 접근 가능한 주소인지 확인하세요. |
| 8787 포트가 사용 중 | 이미 실행 중인 서버 주소에 접속하거나 기존 서버 프로세스를 확인하세요. |
| 레이스 시작 버튼이 비활성화 | 2명 이상인지, 참가자 전원이 준비했는지 확인하세요. |
| 온라인에서 정지가 안 됨 | 정상 동작입니다. Esc는 자신의 조작 메뉴만 엽니다. |

문제 제보 시 버전, 맵, 재현 순서, 기대한 동작과 실제 동작을 알려 주세요. 비밀번호·토큰·개인 주소가 포함된 로그는 공개 이슈에 올리지 마세요.
