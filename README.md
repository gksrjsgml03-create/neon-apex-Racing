# NEON APEX · Desktop V1.1

독립 Windows 창에서 실행하는 싱글플레이 카트 레이싱 프로토타입입니다. Electron 실행 엔진을 포함하며 브라우저 실행이나 로컬 웹 서버가 필요하지 않습니다. 렌더링은 기존 Canvas 2.5D 방식입니다.

## 바로 실행

`start-game.cmd`를 더블 클릭하세요. 또는 `dist/Neon Apex-win32-x64/NeonApex.exe`를 실행하세요.

배포할 때는 exe만 복사하지 말고 `Neon Apex-win32-x64` 폴더 전체를 전달하세요. 실행 엔진이 포함되어 있어 Node.js를 별도로 설치할 필요가 없습니다. 현재는 서명되지 않은 휴대용 개발 빌드이며, 스토어 배포용 설치 프로그램은 아닙니다.

## 조작

| 키 | 기능 |
| --- | --- |
| ↑ / W | 가속. 후진 중에는 먼저 정지한 뒤 전진 |
| ↓ / S | 브레이크. 계속 누르면 정지 후 후진 (최대 60 km/h) |
| ← → / A D | 조향. 후진 시 조향 방향도 반대로 적용 |
| Shift + 조향 | 드리프트. 게이지 55% 이상에서 드리프트를 끝내면 부스터 지급 |
| Ctrl | 부스터 사용 (전진 중, 최대 3개 보유) |
| E | 페이즈 전환 (진입 시 에너지 25% 이상 필요) |
| Esc | 일시 정지 / 복귀 |
| F11 | 전체 화면 / 창 모드 (데스크톱 앱) |

왼쪽·오른쪽 Shift/Ctrl 모두 지원합니다. 속도계의 `R · REVERSE`는 후진 상태입니다. 후진으로 출발선을 반복 통과해도 랩은 중복 집계되지 않습니다. 다른 창으로 이동하면 자동 정지합니다.

## 게임과 차별점

- 네온 시티 코스, AI 5대, 3랩 경주, 순위와 랩 기록
- 드리프트, 부스터, 노외 감속, 상대 카트 접촉
- 페이즈 시프트: 좁아지는 고속 도로, AI 통과, 중앙 가속 구간, 에너지 소모
- 개인 최고 기록은 현재 앱의 로컬 데이터에 저장 (이전 브라우저 기록과 별도)
- 선택형 합성 엔진음. 폰트 연결 실패 시 시스템 폰트로 플레이 가능

기획 소개: “드리프트로 모은 에너지를 언제 다른 차원에 투자할지 선택하는 카트 레이싱을 만들었습니다.” 기존 카트라이더 모든 버전의 기능 유무를 검증한 비교 주장은 아닙니다. 원작의 캐릭터·로고·음원은 포함하지 않습니다.

## 개발

Node.js 22.12 이상을 사용합니다 (이 프로젝트에서는 Node 24 사용).

```text
npm install
node node_modules/electron/install.js
npm start
npm run build:win
```

설치 스크립트가 허용된 일반 환경에서는 Electron 엔진 설치가 자동 수행됩니다. 위 명시적 설치 명령은 엔진이 없는 경우에도 사용할 수 있습니다. 웹 개발용 실행만 필요한 경우 `npm run start:web`을 사용합니다.

- `desktop/main.cjs`: 앱 창, 로컬 파일 프로토콜, 전체 화면, 앱 권한 경계
- `src/input.js`: 키 입력 → 게임 동작 변환
- `src/vehicle.js`: 전진·제동·후진 속도 처리
- `src/race.js`: DOM과 독립적인 경주 규칙 및 AI
- `src/track.js`, `src/render.js`, `src/audio.js`: 코스, 화면, 소리
- `src/main.js`: 화면 상태와 입력 연결
- `scripts/package.mjs`: Windows 실행 폴더 생성

변경 범위 검증은 `npm run test:controls` (후진·출발선·노외·키 매핑 4개), 기존 경주 규칙은 `npm test`, 구문 확인은 `npm run check`로 분리합니다. 전체 테스트를 시각 수정마다 반복하지 않습니다.

## 이후 온라인 출시

이번 버전은 오프라인 싱글플레이입니다. 현재의 입력 / 주행 / 화면 분리를 기반으로 다음 단계에서 서버가 판정하는 경주 상태, 고정 주기 시뮬레이션, 방 생성·매칭, 지연 보정과 재접속을 구현해야 합니다. 실제 온라인 서버, 계정, 결제 및 모바일 배포는 아직 없습니다. Electron은 이번 Windows 데스크톱 배포 선택이며, 모바일 출시에는 별도 플랫폼 대응이 필요합니다.

Git으로 로컬 버전을 관리합니다. V1.0은 보존하고 V1.1에서 앱 전환과 조작 변경을 기록합니다. GitHub 공개는 사용자 플레이 후 진행합니다.
