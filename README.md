# NEON APEX · V1

카트 레이싱에서 영감을 받은 독자적인 싱글 플레이 아케이드 레이싱 프로토타입입니다. 원작의 캐릭터, 로고, 음원은 포함하지 않습니다. 외부 게임 엔진이나 패키지 설치 없이 Node.js 20.11 이상과 최신 데스크톱 브라우저로 실행합니다.

## 실행

이 폴더에서 `npm start`를 실행한 뒤 http://localhost:4173 에 접속하세요. Windows에서는 `start-game.cmd`를 더블 클릭해도 됩니다. 서버 창을 닫으면 종료됩니다.

## 조작

| 키 | 기능 |
| --- | --- |
| ↑ / W | 가속 |
| ↓ / S | 브레이크 |
| ← → / A D | 조향 |
| Space + 조향 | 드리프트: 에너지 충전, 게이지 55% 이상에서 키를 놓으면 부스터 지급 |
| Shift | 부스터 사용 (최대 3개 보유) |
| E | 페이즈 전환 (진입 시 에너지 25% 이상 필요) |
| Esc | 일시 정지 / 복귀 |

처음에는 ↑를 계속 누르고 코너에서 짧게 조향하세요. 도로 밖에서는 감속합니다. 드리프트는 일반 조향보다 빠르게 회전합니다. 화면 오른쪽 위 SOUND OFF 버튼으로 합성 엔진음을 켤 수 있습니다.

## 차별화 기획: 페이즈 시프트

“드리프트로 모은 에너지를 언제 다른 차원에 투자할지 선택하는 카트 레이싱을 만들었습니다.”

STREET에서는 넓은 도로에서 AI와 경쟁합니다. FLUX에서는 최고속도가 올라가고 AI와 충돌하지 않으며, 중앙의 빛나는 구간이 추가 가속을 줍니다. 대신 도로가 좁아지고 에너지가 초당 소모됩니다. E로 일찍 복귀할 수도 있습니다. 이는 이 프로젝트의 기획 설명이며, 기존 카트라이더 모든 버전과의 기능 비교를 검증한 주장은 아닙니다.

## V1 범위와 구조

- 가상 원근감을 사용하는 Canvas 2.5D 렌더링, 네온 시티 트랙 1개
- 3랩, AI 5대, 순위, 랩 기록, 브라우저에 저장되는 개인 최고 기록
- 드리프트 / 부스터 / 페이즈 에너지 / 고속 구간 / 접촉 및 노외 감속
- 일시 정지, 재시작, 포커스를 잃으면 자동 정지, 선택형 합성 사운드
- 키보드 PC 전용. 멀티플레이, 실제 3D 물리, 모바일 터치, 유저 계정은 미포함
- `src/race.js`: 물리 및 경주 규칙 (DOM 독립)
- `src/track.js`: 코스 데이터
- `src/render.js`: 도로, 카트, 도시, 미니맵
- `src/audio.js`: 합성 엔진음
- `src/main.js`: 입력 및 화면 상태

폰트는 Google Fonts 사용을 시도하며, 연결이 없으면 시스템 폰트로 동작합니다. 게임 자체는 외부 자산을 요구하지 않습니다.

## 최소 검증 및 Git

`npm run check`는 구문만 확인합니다. `npm test`는 카운트다운, 에너지/부스터, 완주/초기화의 3개 핵심 경계만 확인합니다. 시각 수정마다 전체 테스트를 반복할 필요는 없습니다.

로컬 Git으로 V1을 기록합니다. GitHub에는 사용자 플레이 후 피드백을 반영하여 올릴 예정입니다. 서버는 로컬 PC(127.0.0.1)에만 연결됩니다.
