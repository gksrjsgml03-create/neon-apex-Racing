# NEON APEX · Desktop V1.2

독립 Windows 창에서 실행하는 싱글플레이 카트 레이싱 프로토타입입니다. Electron 실행 엔진을 포함하며 브라우저 실행이나 로컬 웹 서버가 필요하지 않습니다. 렌더링은 기존 Canvas 2.5D 방식입니다.

## 바로 실행

`start-game.cmd`를 더블 클릭하세요. 또는 `dist/Neon Apex-win32-x64/NeonApex.exe`를 실행하세요.

배포할 때는 exe만 복사하지 말고 `Neon Apex-win32-x64` 폴더 전체를 전달하세요. 실행 엔진이 포함되어 있어 Node.js를 별도로 설치할 필요가 없습니다. 현재는 서명되지 않은 휴대용 개발 빌드이며, 스토어 배포용 설치 프로그램은 아닙니다.

## 조작

| 키 | 기능 |
| --- | --- |
| ↑ / W | 가속. 후진 중에는 먼저 정지한 뒤 전진 |
| ↓ / S | 브레이크. 계속 누르면 정지 후 후진 (최대 60 km/h) |
| ← → / A D | 조향. 전진·후진 모두 누른 방향대로 이동 |
| Shift + 조향 | 드리프트. 게이지 55% 이상에서 드리프트를 끝내면 부스터 지급 |
| Ctrl | 부스터 사용 (전진 중, 최대 3개 보유) |
| E | 페이즈 전환 (진입 시 에너지 25% 이상 필요) |
| Esc | 일시 정지 / 복귀 |
| F11 | 전체 화면 / 창 모드 (데스크톱 앱) |

왼쪽·오른쪽 Shift/Ctrl 모두 지원합니다. 속도계의 `R · REVERSE`는 후진 상태입니다. 후진으로 출발선을 반복 통과해도 랩은 중복 집계되지 않습니다. 다른 창으로 이동하면 자동 정지합니다.

## 5단계 맵 선택

메인 화면의 맵 카드를 선택하고 시작 버튼을 누르세요. 모든 맵은 처음부터 선택 가능합니다. 맵별 최고 기록과 마지막 선택 맵이 저장됩니다. 코스 경로에서 커브와 미니맵을 함께 생성하므로 선택 카드와 실제 주행 코스가 같은 형태를 사용합니다.

| 단계 | 맵 | 주행 특징 |
| --- | --- | --- |
| 1 / 입문 | 코랄 코스트 | 넓은 해안 도로, 완만한 U턴 |
| 2 / 초급 | 포레스트 리본 | 숲속 연속 S커브와 고저차 |
| 3 / 중급 | 레드록 헤어핀 | 협곡의 더블 헤어핀, 부스터 직선 |
| 4 / 고급 | 알파인 스위치백 | 설산의 좁은 산길과 연속 급커브 |
| 5 / 마스터 | 네온 오버패스 | 도심 시케인, 고가도로와 터널 형태의 구조물 |

급커브에서는 먼저 속도를 줄이거나 Shift와 방향키를 함께 눌러 드리프트하세요. 코너 안내와 도로 바깥의 화살표 표지판이 회전 방향을 알려줍니다. 난이도가 올라갈수록 도로가 좁아지고 강한 커브가 많아집니다.

## 사운드

기본값은 SOUND ON입니다. 레이스 시작 클릭으로 오디오를 활성화합니다. 음악은 오리지널 신시사이저 멜로디·베이스·드럼 패턴이며, 코스별로 템포와 음높이가 달라집니다. 엔진·노면 소리는 속도에 따라 변하고, 드리프트에는 타이어 마찰음, 부스터에는 상승음과 바람 소리가 재생됩니다. 카운트다운 신호음도 포함합니다.

메인 화면에서 음악과 효과음 볼륨을 별도로 조절하고 ‘소리 미리듣기’를 사용할 수 있습니다. 오른쪽 위 SOUND 버튼으로 전체 음소거가 가능합니다. 다른 창으로 이동하거나 일시 정지하면 소리도 멈춥니다. 소리가 들리지 않으면 앱의 볼륨과 Windows 볼륨 믹서의 Neon Apex 출력을 확인하세요. 외부 음원 파일 다운로드는 필요하지 않습니다.

## 게임과 차별점

- 테마와 코스가 다른 맵 5개, AI 5대, 3랩 경주, 순위와 랩 기록
- 드리프트, 부스터, 노외 감속, 상대 카트 접촉
- 페이즈 시프트: 좁아지는 고속 도로, AI 통과, 중앙 가속 구간, 에너지 소모
- 개인 최고 기록은 현재 앱의 로컬 데이터에 저장 (이전 브라우저 기록과 별도)
- 배경음악과 주행·드리프트·부스터 효과음. 폰트 연결 실패 시 시스템 폰트로 플레이 가능

기획 소개: “드리프트로 모은 에너지를 언제 다른 차원에 투자할지 선택하는 카트 레이싱을 만들었습니다.” 기존 카트라이더 모든 버전의 기능 유무를 검증한 비교 주장은 아닙니다. 원작의 캐릭터·로고·음원은 포함하지 않습니다.

## 개발

Node.js 22.12 이상을 사용합니다 (이 프로젝트에서는 Node 24 사용).

```text
npm install
node node_modules/electron/install.js
npm start
npm run build:win
```

설치 스크립트가 허용된 일반 환경에서는 Electron 엔진 설치가 자동 수행됩니다. 위 명시적 설치 명령은 엔진이 없는 경우에도 사용할 수 있습니다. 웹 개발용 실행만 필요한 경우 `npm run start:web`을 사용합니다.

- `desktop/main.cjs`: 앱 창, 로컬 파일 프로토콜, 전체 화면, 앱 권한 경계
- `src/input.js`: 키 입력 → 게임 동작 변환
- `src/vehicle.js`: 전진·제동·후진 속도 처리
- `src/race.js`: DOM과 독립적인 경주 규칙 및 AI
- `src/tracks.js`: 다섯 코스의 경로, 난이도, 테마와 곡률 생성
- `src/scenery.js`: 테마별 배경과 길가 오브젝트
- `src/render.js`, `src/audio.js`: 화면 및 음악·효과음
- `menu.css`: 맵 선택 화면 (경주 HUD 스타일과 분리)
- `src/main.js`: 화면 상태와 입력 연결
- `scripts/package.mjs`: Windows 실행 폴더 생성

변경 범위 검증은 `npm run test:content` (후진 방향·5코스·맵별 랩 3개), `npm run test:controls` (후진·출발선·노외·키 매핑 4개), 기존 경주 규칙은 `npm test`, 구문 확인은 `npm run check`로 분리합니다. 전체 테스트를 시각 수정마다 반복하지 않습니다. 앱의 `--smoke-test`는 맵 선택 화면 로드와 OfflineAudioContext를 이용한 음악·효과음 5종의 출력 신호를 검사합니다. 이는 스피커의 실제 출력 음량을 대신 확인하지는 않습니다.

## 이후 온라인 출시

이번 버전은 오프라인 싱글플레이입니다. 입력 / 주행 / 화면을 분리하고 60Hz 고정 주기로 주행을 갱신합니다. 다음 단계에서 서버가 판정하는 경주 상태, 방 생성·매칭, 지연 보정과 재접속을 구현해야 합니다. 실제 온라인 서버, 계정, 결제 및 모바일 배포는 아직 없습니다. Electron은 이번 Windows 데스크톱 배포 선택이며, 모바일 출시에는 별도 플랫폼 대응이 필요합니다.

Git으로 로컬 버전을 관리합니다. V1.0과 V1.1은 보존하고 V1.2에서 5코스·후진 방향 수정·사운드를 기록합니다. GitHub 공개는 사용자 플레이 후 진행합니다.
