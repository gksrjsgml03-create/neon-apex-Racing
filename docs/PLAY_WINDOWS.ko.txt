NEON APEX Racing V1.6.0 — Windows 실행 안내

1. 다운로드한 ZIP을 우클릭하고 '압축 풀기'로 폴더 전체를 꺼내세요.
2. Neon Apex-win32-x64 폴더의 NeonApex.exe를 실행하세요.
3. Node.js, npm, 게임 엔진을 따로 설치할 필요가 없습니다.
4. exe만 다른 곳으로 옮기지 마세요. resources와 나머지 파일이 모두 필요합니다.

싱글플레이
- 싱글플레이를 선택하고 캐릭터, 카트, 맵을 고른 다음 시작하세요.

PC + 노트북 멀티플레이 (같은 공유기 / 같은 Wi-Fi)
- PC와 노트북 모두 같은 버전의 게임을 다운로드하세요.
- PC에서 멀티플레이 → 닉네임 입력 → 내 PC에서 방 열기를 누르세요.
- 대기실에서 맵 선택 → 초대 복사를 누르고 초대 정보를 노트북으로 전달하세요.
- 노트북에서 멀티플레이 → 초대 정보 붙여넣기 → 참가하기를 누르세요.
- 노트북에서 준비 완료, 방장 PC에서 레이스 시작을 누르면 함께 출발합니다.
- 최소 2명, 최대 8명입니다. 서버를 연 PC는 앱을 계속 실행해 두세요.

접속이 안 된다면
- 두 기기가 같은 공유기에 연결되어 있는지 확인하세요. 유선 PC와 Wi-Fi 노트북도
  같은 공유기에 연결되어 있고 기기 간 통신이 허용되어 있으면 사용할 수 있습니다.
- Windows 방화벽의 사설 네트워크에서 게임 통신이 허용되어 있어야 합니다.
  게임은 방화벽 설정을 자동으로 변경하지 않습니다. 기본 서버 포트는 TCP 8787입니다.
- 게스트 Wi-Fi나 공용 Wi-Fi는 기기 간 통신을 막을 수 있습니다.
- 초대 주소가 127.0.0.1이면 다른 기기에서 접속할 수 없습니다.
- VPN이나 가상 어댑터가 있으면 '초대 주소 설정'에서 공유기에 연결된 PC의 IPv4 주소를
  사용하세요. 예: ws://192.168.0.10:8787
- '포트가 사용 중'이면 이미 실행 중인 게임 서버 주소로 '입력한 서버에 방 만들기'를
  사용하거나, 자신이 실행한 기존 서버를 종료한 뒤 다시 시도하세요.

서로 다른 인터넷 / 외부 장소
- 방장: 멀티플레이 → 인터넷 친구와 방 만들기 → 맵 선택 → 초대 복사.
- 친구: 초대 정보 붙여넣기 → 참가하기 → 준비 완료.
- 방장이 레이스 시작을 누르면 함께 출발합니다. 최소 2명, 최대 8명입니다.
- 무료 임시 서버이므로 운영자 PC와 서버가 켜져 있어야 합니다.
- PC 절전이나 서버 종료 시 연결이 끊깁니다. 상시 서비스는 아닙니다.
- 자세한 설명은 PUBLIC_SERVER.md와 ONLINE.md를 참고하세요.

조작
↑/W 가속 | ↓/S 제동·후진 | ←→/AD 조향
Shift 드리프트 | Ctrl 부스터 | E 페이즈 전환
R 복귀·1초 보호 | C 카메라 | Esc 조작 메뉴 | F11 전체 화면
온라인에서는 Esc를 눌러도 경기가 계속 진행됩니다.

참고
- Windows x64용 휴대용 개발 빌드입니다. macOS, 모바일용 실행 파일이 아닙니다.
- 그래픽 환경이 WebGL 2를 지원해야 합니다.
- 아직 코드 서명된 설치 프로그램이 아니므로 Windows 보안 확인이 표시될 수 있습니다.
- 배경음악은 자동 재생됩니다. 게임 SOUND와 Windows 볼륨 믹서를 확인하세요.
- 기록과 설정은 각 PC에 따로 저장됩니다.
